# dr-ericka-leite-modern-fixed
Fixed, modern Next.js + Tailwind CSS starter for Dra. Éricka Leite — prepared to avoid previous bg-neutralbg issue.

## How to run
1. Extract zip
2. In project folder run:
   npm install
   npm run dev
3. Open http://localhost:3000

Notes:
- Uses inline hex colors for background/buttons to avoid custom utility class issues on different setups.
- Replace OAB number and texts as needed.
